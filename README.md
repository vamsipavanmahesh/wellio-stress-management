# Wellio Stress Management

A web application for kids to manage stress through guided breathing exercises. Simple, accessible, and fun.

## What it does

- **Breathing exercises** with visual guides
- **Calming sounds** to help relax
- **No signup required** - just start breathing
- **Works on any device** - phone, tablet, computer

## Tech stack

- Ruby on Rails 8
- Hotwire (Turbo + Stimulus)
- CSS animations
- Web Audio API

## Quick start

```bash
git clone https://github.com/vamsipavanmahesh/wellio-stress-management.git
cd wellio-stress-management
bundle install
rails s
```

Visit `http://localhost:3000` and start breathing!

## Features

- **Visual breathing circle** that grows and shrinks with your breath
- **Water sounds** for background relaxation
- **Timer** to track your session
- **Accessible** - works with screen readers and keyboard navigation

## How to use

1. Click "Start" to begin
2. Follow the circle - breathe in when it grows, out when it shrinks
3. Listen to the calming water sounds
4. Click "Stop" when you're done
